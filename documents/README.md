# Hospital documents

Place approved, non-identifying hospital documents here. Supported formats:

- `.pdf`
- `.docx`
- `.txt`

Do not upload patient-identifiable records.

After adding or updating files, start the Streamlit app (or click **Rebuild index** in the sidebar). The app fingerprints this folder and re-indexes when content changes.

This folder is intentionally empty in the repo so you can add your real hospital files locally.
